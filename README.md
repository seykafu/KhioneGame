# Khione

An RPG adventure where you play as Khione, a small white Persian cat who washes ashore a mysterious message in a bottle — and sets out across a chain of ten strange islands to discover the truth of her existence.

## The Game

- **Explore** freely: walk, run, jump, and swim across each island.
- **Solve** escape-room-style riddles to travel from island to island — and revisit earlier islands for clues.
- **Collect** items (5 slots, upgradable to 10) and learn cat skills: meows, hisses, and growls.
- **Meet Oreo**, a border collie sidekick who joins the journey.

From the tropical shores of Ahalo to islands that look suspiciously like Canadian neighbourhoods, the journey ends on Island 10 — Agrea — where everything comes together.

## Tech

Built in **Godot 4** (low-poly stylized 3D), targeting a Steam release for PC (Windows/Mac/Linux).

### Running the game

1. Install Godot 4: `brew install --cask godot` (or download from [godotengine.org](https://godotengine.org))
2. Open Godot, click **Import**, and select this folder's `project.godot`
3. Press **▶** (or Cmd+B) to play

### Controls

| Input | Action |
|---|---|
| WASD / arrows | Move |
| Mouse | Camera |
| Shift | Run |
| Space | Jump / paddle up (in water) |
| E | Interact |
| M / H / G | Meow / Hiss / Growl (must be learned) |
| Esc | Release mouse |
